# Mistbound — พันธสัญญาแห่งหมอก

ต้นแบบเว็บเกมภาษาไทยสำหรับเล่นคนเดียว อ้างอิงแนวคิดทีมเล็กและผลการตัดสินใจที่ตรวจสอบได้จากเอกสารออกแบบของผู้ใช้

## เปิดเล่น

จากโฟลเดอร์โปรเจกต์ รัน `python3 -m http.server 8000` แล้วเปิดเว็บผ่านพอร์ต 8000 ในเครื่องที่รันเซิร์ฟเวอร์ ไม่ต้องติดตั้งแพ็กเกจ

- ออกสำรวจ ใช้โจมตี ตั้งรับ ช่วยเหลือ หรือถอนตัว แต่ละคำสั่งคือหนึ่งเทิร์น เกมรอผู้เล่นเสมอ
- ศัตรูโจมตี 16 ต่อคน หรือ 38 ทุกเทิร์นที่สาม ตั้งรับหารความเสียหายด้วยสามและปัดขึ้น
- ตัวละครล้มมีเวลาอีกสองคำสั่งให้ช่วยก่อนตายถาวร ถอนตัวพาคนที่ยังไม่ตายกลับฐาน
- ชนะรับ 60 ทอง พักฟื้นฟรีที่ฐาน การเริ่มใหม่ล้างเซฟหลังยืนยัน
- เซฟอัตโนมัติด้วย localStorage ในเบราว์เซอร์และ origin เดิม การล้างข้อมูลเบราว์เซอร์จะลบเซฟ

`engine.mjs` แยกกติกาแบบ deterministic ออกจาก `app.mjs` และหน้าจอ ยังไม่มีการสุ่ม จึงไม่ต้องใช้ seed

ขอบเขตปัจจุบัน: ภารกิจเดียว ฮีโร่คงที่สามคน บทพูดแม่แบบจากเหตุการณ์จริง ยังไม่มี LLM, อัญเชิญ, ฝึก, อุปกรณ์, ส่งออกเซฟ หรือหอคอยหลายชั้น ภาพใช้ CSS และสัญลักษณ์ ฟอนต์ออนไลน์เป็นตัวเลือกและมี sans-serif สำรอง
