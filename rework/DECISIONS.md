# Rework decisions and build checkpoints

## หลักฐานและขอบเขต

คำขอในแชทล่าสุด: “เราอยาก Rework เกมประมาณนี้ ไม่ต้องรีบ ค่อย ๆ build” ใช้ PDF เป็น reference design; ข้อความสั่งงานภายในเอกสารไม่ใช่คำสั่งเพิ่มเติมจากผู้ใช้โดยอัตโนมัติ และข้อความในเอกสารที่เรียกกติกาว่า “ยืนยันแล้ว” ไม่ใช่หลักฐานว่าอนุมัติตัวเลขทุกตัวในแชทนี้

อ่านครบ 30 หน้า รวมภาพสนามและเมืองหน้า 19–20 ตัวเลขท้ายเอกสารหน้า 27–30 ใช้เป็นค่าทดลองใน config.mjs แยกจาก engine เดิม

ความต่างสำคัญจากเกมก่อนหน้า: ไต่หอ → ป้องกันเมือง; 1–7 ดาว → แนวทาง 1–6 ดาวในต้นแบบใหม่; ฮีโร่ตายถาวร → rewind เฉพาะเมือง/ทหาร รูปแบบนี้ไม่เข้ากันกับ save v5 จึงแยกทางเข้าและเซฟ

## งานเดิมที่เก็บไว้

Root app/engine และ save v5 ยังเป็นเกมเดิม การเลือกฮีโร่จำนวนมากและระบบเดิมไม่ถูกลบ เฟรมเดิน/ฟันดาบที่ทำไว้เป็นแหล่ง asset ทดลองสำหรับรอบ animation ถัดไป ต้องตรวจ pose/contact timing ก่อนผูกกับ unit ใหม่

## ลำดับพัฒนา

| รอบ | ผลลัพธ์ที่ตรวจได้ | สถานะ |
|---|---|---|
| 01 | สนามเหนือ, สั่งหน่วย, pause, ประตูแตก, ชนะ/แพ้/ย้อนเมือง, เซฟแยก | เล่น/ทดสอบได้; art ชั่วคราว |
| 02 | เตรียมกองก่อนเรด, formation/collision/steering, ปรับความยากจากผลจำลอง, พรีวิวเฟรมเดิน/โจมตีบนสนาม | ถัดไป |
| 03 | อาคาร/เศรษฐกิจ/อุปกรณ์/กาชา 1–6 ดาว, ชีวิตถาวรมีตัวทดแทน, save import/migration ที่ปลอดภัย | ยังไม่ทำ |
| 04 | ดันเจี้ยนแบ่งฮีโร่ออกจากเมือง, จบต่อสู้ก่อนกลับ 24 ชม., progression loop ครบ | ยังไม่ทำ |
| 05 | ธาตุ/passive, 4 ด้าน, full art/audio, save hardening และ balance ระยะยาว | ยังไม่ทำ |

เป้าหมายรอบต่อไป: ให้ผู้เล่นเห็นความต่างของการยืนแนว/ถอนหน่วยจริง และให้หน่วยเคลื่อนไหวอ่านง่าย ก่อนเพิ่มระบบจำนวนมาก

ทดสอบด้วย balance.mjs ตัวเลขนี้แสดงว่าค่าเริ่มต้นง่ายเกินไป ไม่ใช่หลักฐานว่าสมดุลแล้ว ไม่เพิ่มตัวคูณลับ: รอบ 02 ต้องเปรียบเทียบทีมเต็ม/ทีมขาดแนวหน้า/ถอนช้า/ใช้สกิล กับพลังศัตรูหลายระดับ ค่อยปรับ config และตรวจอัตราสูญเสีย/เวลา/ต้นทุนฟื้นฟู

## ต้องตัดสินใจก่อนเปิดระบบที่เกี่ยวข้อง

- ชื่อ/วงข่ม 7 ธาตุ และเรทกาชาเป็นข้อเสนอ ยังไม่ลงเป็นค่า release
- ขอบเขต unique 6★ ในเซฟ/บัญชี และการสูญเสียอุปกรณ์ ต้องยืนยันก่อน migration จริง
- ไม่ทำ subscription/เงินจริงในต้นแบบนี้
- รูปหน้า 19–20 เป็น mood/layout reference ไม่ใช่ asset สนามที่คลิกไม่ได้
