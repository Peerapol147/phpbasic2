# Mistbound — City Defense, checkpoint 01

ต้นแบบกติกาแยกจากเกมหลัก อ้างอิง `MISTBOUND_Final_Prototype_v1.pdf` (30 หน้า, 6 พ.ย. 2026) ตามคำขอให้ค่อย ๆ rework ไม่ใช่ฉบับครบระบบหรือภาพสุดท้าย

## เล่น / ทดสอบ

เปิด `/rework/` บนเว็บเดียวกับเกมเดิม หรือรันจากราก repository:

```sh
python3 -m http.server 8000
node rework/tests/simulation.test.mjs
node rework/tests/balance.mjs
node rework/tests/browser.cjs
```

Browser test ใช้ Playwright + Chromium ที่ `/usr/bin/chromium` และ server port 8000

- เริ่มเรดด้วยฮีโร่มีชีวิตทั้งหมด (รอบนี้ยังเลือกกองก่อนลงไม่ได้)
- คลิกฮีโร่/หมู่ทหารเพื่อเลือก, Shift เพิ่ม/เอาออก, คลิกพื้นเพื่อเดิน, คลิกขวาศัตรูเพื่อกำหนดเป้า
- Space หยุดเวลา แล้วสั่งตั้งรับ/ถอน/สกิลได้ คำสั่งทำงานเมื่อเล่นต่อ
- เปลี่ยนกล้องด้วยปุ่มโซนหรือ minimap, ล้อเมาส์ซูม
- ทดสอบการสูญเสียโดยเปิด “เครื่องมือทดสอบและเซฟ” แล้วเลือกโหมดก่อนเริ่มเรด
- ชนะกลับเมืองเพื่อรักษา/เกณฑ์ทหาร/ซ่อม; แพ้ย้อนเมืองก่อนกลับเมือง

## สิ่งที่ทำงานแล้ว

Simulation 20Hz แยกจากการวาดภาพ, ทางเหนือหนึ่งด้าน + ถนนชั้นใน, ประตูแตกไม่จบเรด, ป้อมแตกแพ้, 5 ฮีโร่ + 3 หมู่ทหาร, 3 ชุดเรด ชุดละ 3 ระลอก, โจมตี/กระสุน/สกิลใช้มานาและคูลดาวน์, boss telegraph, death ledger, การจ่ายรางวัลและย้อนเมืองครั้งเดียวต่อ raid ID, ฟื้นฟูเมืองพื้นฐาน

## เซฟ

ใช้ `mistbound-city-prototype-v1` เท่านั้น ไม่อ่านหรือแก้ `mistbound-v5` ของเกมเดิม ไม่มี migration ดาว 7 → 6 อัตโนมัติ โหลดระหว่างเรดจะหยุดเวลารอผู้เล่น; ไม่จำลองการต่อสู้ออฟไลน์ ไม่มี offline production ใน checkpoint นี้ บันทึกทุก 1 วินาทีและทันทีเมื่อเกิด death/settlement/rewind/breach หรือคำสั่ง UI ข้อมูลทั้งหมดเป็น snapshot JSON หนึ่งรายการใน localStorage

ดาวน์โหลดสำรองได้ การเริ่มใหม่ถามยืนยันและสำรองเซฟเดิมไว้ที่ key `-backup` หนึ่งชุด การนำเข้าไฟล์สำรอง/การตรวจเซฟเชิงลึก/หลายแท็บ/เซฟบน server ยังไม่ได้ทำ ไม่ควรใช้เป็นเซฟจริงระยะยาว

## ข้อจำกัดที่ตั้งใจเปิดเผย

- ภาพเป็น geometry/glyph สำหรับตรวจตำแหน่ง ไม่ใช่ final art หรือ animation production; เฟรมดาบเดิมอยู่ `/walk-preview.html` ยังไม่ผูกกับ simulation ใหม่
- กาชา 1–6★, passive, ธาตุจริง, ดันเจี้ยน, โรงตีเหล็ก, อัปเกรดอาคาร, ระบบเศรษฐกิจครบวงจร และอีก 3 ด้าน ยังไม่เปิด
- ธาตุ E1–E7 เป็นข้อมูลสำรอง ตัวคูณปัจจุบัน 1 ไม่อ้างว่ามีธาตุครบแล้ว
- ผลิตทรัพยากร/รักษา/เกณฑ์เฉพาะช่วงเมือง; เริ่มเรดหยุดการรักษาของฮีโร่ที่ออกไป
- ศัตรู/หน่วยยังเดินบนตาราง 4 ทิศ ยังต้องพัฒนา steering, collision กับอาคาร, formation และ interpolation
- หากเสียฮีโร่หมด ต้องเริ่มเซฟทดลองใหม่ กาชาทดแทนยังไม่พร้อม
- ตัวเลขจากภาคผนวกเป็น baseline ทดลอง ไม่ใช่ balance ที่รับรองแล้ว ดู DECISIONS.md
