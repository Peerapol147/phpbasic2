## ลำดับการแก้ที่สอดคล้องกับหลักฐาน

1. สนามต่อสู้กับระบบหลายคลื่น: จุดเข้า เก็บ HP/คูลดาวน์ข้ามคลื่น จบชั้นหลังคลื่นสุดท้ายเท่านั้น
2. แยกจังหวะ prepare → strike/projectile → impact → recover; damage, heal และ VFX อ้างเหตุการณ์เดียวกัน ทดสอบว่า pause/ความเร็วไม่ทำให้ยิงหรือรับรางวัลซ้ำ
3. AI หาเป้าและตำแหน่งยืน: แนวหน้าเข้าประชิดไม่ซ้อนกัน แนวหลังรักษาระยะ มีทางเลือกเมื่อติดขอบ ไม่โยกทั้งภาพเพื่อแทนการเดิน
4. คลัง Active/Passive ห้าคลาส: สกิลมีเป้าหมาย เงื่อนไข trigger ระยะ เวลา ผลสถานะ และงบพลังชัดเจน; บันทึกชุดสกิลรายตัวในเซฟ แทนเลือกตาม ID อย่างเดียว
5. วัดบาลานซ์ใหม่บนการสู้หลายคลื่น รวมผลฮีล/โล่/CC และต้นทุน cooldown; ผลจำลอง 30 กรณีเดิมเป็น regression ของระบบเดิม ไม่ยืนยันสมดุลรูปแบบใหม่

รายการนี้เป็นผลตรวจและข้อกำหนดสำหรับแก้รอบถัดไป ยังไม่ได้ติดตั้งการแก้เหล่านี้ในเกม และไม่มีการเปลี่ยนเซฟหรือเผยแพร่โค้ดในรอบตรวจนี้
